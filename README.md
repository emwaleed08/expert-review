# UMD Heuristic Review

Keep `index.html`, `img/` and `fonts/` together in one folder.

## Save as PDF (Chrome)
1. Open `index.html` in Chrome.
2. Press Cmd + P (Mac) or Ctrl + P (Windows).
3. Destination: **Save as PDF**.
4. More settings: turn on **Background graphics**.
5. Click Save. Page size (US Letter) is already set; each heuristic prints on its own page.

## Editing
Open `index.html` in any text editor. Each heuristic is a `<section class="h">` block:
the Problem is in `<p class="prob">`, the Description in `<p class="desc">`.
Dashed call-outs on the wireframes are `<div class="new">`, and their labels are `<span class="lab">`.
